# salemdemsva.com

Website for the Salem City Democratic Committee.

## ADDING CONTENT

To add new pages, add a new [markdown file](https://www.markdownguide.org/basic-syntax/) in [content/posts](content/posts/) with the `title`, `date`, and `description`.  Copy and rename an existing file as a starting point.

Markdown files in `content/posts/` are added to the site and deployed automatically after saving the new commit.

## AUTOMATIC DEPLOYMENT

Changes to the `main` branch (commits and merges) are deployed automatically.
